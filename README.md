# Homebrew tap for Nagare

[Nagare](https://github.com/Nik-code/nagare) is a Liquid Glass torrent client for macOS, a redesigned fork of Transmission.

```bash
brew tap nik-code/nagare
brew trust nik-code/nagare
brew install --cask nagare
```

Needs an Apple Silicon Mac on macOS 26 or later. Nagare is not notarised, so macOS will ask you to choose Open Anyway in Privacy & Security the first time.
